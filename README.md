# 南大轻搭子 NJU Partner

## 项目目标

南大轻搭子是一个面向南京大学学生的校园轻量组队 Web 平台，用来解决学生在自习、运动、竞赛、课程学习、拼单、出行、讲座同行等场景中临时找搭子的需求。

项目不定位为泛社交平台，也不做复杂好友关系，而是围绕“发布组队帖、筛选浏览、报名申请、楼主审核、成员展示、评论沟通、通知提醒”的闭环，提高校园临时组队的信息匹配效率。

## 功能介绍

### 用户模块

- 用户注册与登录。
- JWT 登录态维护。
- 查看和修改个人资料。
- 支持普通用户和管理员角色。
- 用户资料包括昵称、校区、年级、专业等，用于组队场景展示和筛选。

### 组队帖模块

- 发布组队帖，填写标题、类型、描述、校区、地点、活动时间、人数需求、年级限制、专业限制、联系方式等。
- 首页展示组队帖列表，支持关键词、校区、类型、状态等筛选。
- 帖子详情页展示活动信息、当前人数、已报名成员、报名列表、评论区等。
- 楼主可以编辑或关闭自己发布的帖子。
- 当前人数按“楼主 + 已通过报名成员”统计。

### 报名与审核模块

- 用户可以对感兴趣的帖子发起报名。
- 报名后显示待审核状态。
- 用户可以取消报名，取消后允许再次报名。
- 楼主可以查看报名列表，并对申请进行通过或拒绝。
- 通过后的成员会展示在帖子详情页的已报名成员区域。

### 评论与回复模块

- 帖子详情页支持发表评论。
- 支持轻量回复他人评论。
- 评论回复会触发站内通知，提醒被回复用户查看。

### 通知模块

- 首页页眉常驻通知入口。
- 支持未读红点提醒。
- 支持查看通知列表、标记单条已读、全部已读。
- 通知覆盖报名申请、审核状态变化、评论回复等场景。

### 个人中心

- 查看和编辑个人资料。
- 查看我的发布。
- 查看我的报名。
- 查看我的收藏。

### 后台管理

- 管理员可以查看和管理帖子。
- 管理员可以查看用户列表，并进行封禁或解封。
- 管理员可以查看评论列表，并删除不合规评论。
